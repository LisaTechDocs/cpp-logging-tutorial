# Set up a C++ development environment on a Chromebook

This guide explains how to set up a Linux development environment on a Chromebook to build and run a C++ application using the open-source spdlog logging library.

The setup uses Debian Linux, GCC, CMake and Git. Once configured, the environment can be used to build, test and publish the example application to a public GitHub repository.

## Prerequisites

- A Chromebook that supports the Linux development environment
- An internet connection
- A GitHub account
